Build a complete, polished, interactive full-stack hackathon project named:

# AI-3D ULPIN Generation & Vertical Property Mapping System

## 1. PROJECT OBJECTIVE

Create a modern web application that demonstrates an AI-powered 3D cadastral/property mapping system.

The system solves the limitations of traditional 2D land records, which cannot properly represent:

* Multi-storey buildings
* Individual floors
* Apartment units
* Basements
* Underground parking
* Empty land parcels
* Vertical property boundaries
* Building footprints
* Underground infrastructure

The application should demonstrate how images, architectural plans, GIS-style property data, and AI analysis can be transformed into an interactive 3D property representation.

The complete demonstration pipeline should be:

IMAGE / PROPERTY DATA
↓
AI ANALYSIS
↓
BUILDING & LAND DETECTION
↓
3D MODEL GENERATION
↓
VERTICAL PROPERTY MAPPING
↓
PROTOTYPE 3D ULPIN GENERATION
↓
BOUNDARY VALIDATION
↓
3D PROPERTY VISUALIZATION
↓
PROPERTY REPORT

IMPORTANT:
This is a hackathon prototype. Do NOT claim that the generated ULPIN is an official government ULPIN. Clearly label it everywhere as:

"Prototype 3D ULPIN — Hackathon Demonstration"

The goal is to demonstrate the concept and workflow.
